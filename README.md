# Swimming Results Analyzer

Программа для обработки и анализа результатов соревнований по плаванию.

Проект показывает работу с данными: чтение Excel, очистку, расчёт статистики и сохранение результатов.

## Возможности
- Чтение результатов из Excel-файла
- Преобразование времени из формата `ММ,СС,сс` в секунды
- Расчёт среднего, лучшего и худшего результата
- Группировка по дистанциям и полу
- Сохранение обработанных данных в новый Excel-файл

## Как запустить

1. Установи зависимости:
```bash
pip install pandas openpyxl
```

2.  Положи файл competition_data.xlsx в папку data/

3.  Запусти программу:
```bash
python main.py
```

## Формат входных данных
Excel-файл с листом Результаты и колонками:
•  last_name
•  first_name
•  event_name
•  time_seconds (формат ММ,СС,сс)
•  gender
•  team
